## 🧑‍💻 About Me

我在做一件事：**把多智能体系统从玩具做到工程**。

- 🤖 专注 **AI / Agent 开发** —— 从教学级极简实现，到可落地的智能体产品，再到企业级持久化执行内核
- 🧭 工程观：**模型做判断，代码搬数据** —— 安全边界、状态管理、可审计性交给确定性代码，而不是祈祷 prompt
- 🎓 就读于 **北京工业大学**（Beijing University of Technology）· 计算机科学与技术专业
- 🌱 正在探索 **AgentScope / Agno / ChatDev** 等多智能体框架与数字员工平台
- 🎯 状态：`Focusing` —— Talk is cheap, show me the Agent!
- 📫 找我玩：欢迎在 [Issues](https://github.com/BlueX888/BlueX888/issues) 留言
